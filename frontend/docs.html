Project Overview

PhishShield AI is a proactive security pipeline. By combining deterministic whitelisting with LSTM-based deep learning, it provides a robust shield against modern social engineering.

System Architecture

The system follows a Synchronous Multi-Layer Defense:

  • Layer 1: Static Analysis — TLD extraction and Whitelist verification.
  • Layer 2: Neural Inference — LSTM model analyzes unknown URL sequences.
  • Layer 3: Threat Mapping — Categorizes confidence into High/Medium/Low risk levels.

Deep Learning Logic

We utilize Long Short-Term Memory (LSTM) networks for URL analysis. Unlike older Random Forest methods, LSTMs treat URLs as time-series data of characters, capturing the "intent" behind the domain structure.
