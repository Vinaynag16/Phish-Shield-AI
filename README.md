# Phish-Shield AI 🛡️
**Intelligent Phishing Detection using Machine Learning**

Phish-Shield AI is a full-stack web application designed to identify malicious URLs and phishing messages. By leveraging Natural Language Processing (NLP) and Machine Learning models, the system analyzes text patterns and URL structures to provide real-time security verdicts.

---

## 🚀 Features
* **Dual-Mode Analysis:** Separate scanners for suspicious **URLs** and **Email/SMS text**.
* **AI-Powered Verdicts:** Real-time classification (Safe vs. Danger) with confidence scores.
* **Analysis History:** Local storage tracking of the last 5 scans for quick reference.
* **Clean UI:** Responsive, dark-themed dashboard built for clarity and speed.

## 📂 Project Structure
* `frontend/` - The web interface (HTML, CSS, JavaScript).
* `backend/` - FastAPI server handling the logic and model inference.
* `models/` - Trained Machine Learning model files (`.joblib` or `.pkl`).
* `notebooks/` - Research area containing Data Cleaning, EDA, and Model Training scripts.
* `requirements.txt` - Python dependencies required to run the backend.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API).
* **Backend:** Python 3.x, FastAPI.
* **ML Libraries:** Scikit-learn, Joblib, Pandas.
